# 🌀 스틱맨 아레나

브라우저에서 바로 실행되는 **스틱맨 대전 게임**입니다. 설치나 빌드 없이 `index.html` 하나로 동작합니다.

- 최대 **4인 난전** (4인일 때는 맵이 넓어지고 카메라가 줌아웃)
- **12명**의 캐릭터, 캐릭터마다 **패시브 1 + 스킬 2 + 궁극기 1 + 영역전개 1**
- **영역대전**: 상대 영역이 펼쳐진 동안 내 영역을 펼치면, 공격 버튼 연타로 승부
- 로컬 2인 / CPU 대전 지원, 빈 자리는 CPU가 채움
- 먼저 2판을 이기면 승리

## 실행 방법

### 1) 바로 열기
`index.html`을 브라우저(Chrome 권장)로 열면 됩니다.

### 2) GitHub Pages로 배포
1. 이 폴더의 파일을 저장소 루트에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch` → `main` / `/(root)` 선택
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 플레이

## 조작

| | 이동 | 점프 | 주먹 | 스킬1 | 스킬2 | 궁극기 | 영역 |
|---|---|---|---|---|---|---|---|
| **1P** | A / D | W | F | G | H | J | K |
| **2P** | ← / → | ↑ | , | . | / | ; | ' |

모바일에서는 화면 아래 버튼으로 조작합니다. 버튼 이름이 곧 선택한 캐릭터의 기술 이름입니다.

- **게이지(보라색)**: 때리거나 맞으면 참. 50 이상이면 궁극기, 100이면 영역전개
- 4인전은 사람 2명(로컬)까지 + CPU로 구성됩니다.
